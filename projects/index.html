Project 1 — PhD Research: Closed-loop Human–AI Interaction

[cite_start]One-line summary: I develop a closed-loop framework to predict user acceptance, enable scalable real-time interaction, measure user experience from dialogue, and regulate agent behaviour via feedback + bang–bang control—demonstrated in the context of shared autonomous vehicles (SAVs)[cite: 472, 473].
[cite_start]

What this project delivers [cite: 474]

    [cite_start]
  • Prediction: data-driven modelling and interpretable visualisation of psychological drivers of acceptance[cite: 475].
    • [cite_start]
  • Interaction platform: an LLM-based conversational testbed for open-domain human–agent interaction studies at scale[cite: 476].
    • [cite_start]
  • Measurement: interaction-level sentiment/subjectivity analysis to quantify user experience signals from dialogue[cite: 477].
    • [cite_start]
  • Regulation: a closed-loop, bang–bang control mechanism that adjusts agent response characteristics in real time to maintain target experience states, supported by analytical guarantees (e.g., wrong-step probability and time-in-band)[cite: 478].
[cite_start]

Key outputs [cite: 479]

  • Ethics-approved user studies and a curated interaction dataset for quantitative analysis[cite: 480].
    • [cite_start]
  • Measurement pipeline for experience signals in open-domain dialogue[cite: 481].
    • [cite_start]
  • Control-theoretic framework for adaptive, value-aligned interaction regulation[cite: 482].
